# FormReady

**FormReady** is a responsive web application that helps people prepare for long online applications without repeatedly typing the same information, missing documents, or forgetting deadlines.

## Product goal

Users save a private personal profile once, choose an application template, and receive:

- a tailored document checklist;
- reusable, easy-to-copy answer cards;
- saved progress; and
- deadline reminders.

The user remains responsible for reviewing and submitting information on third-party websites. FormReady will not automatically submit external forms.

## Planned stack

- Java 21 and Spring Boot for the application
- Selenium, Cucumber, TestNG, and Page Object Model for UI automation
- JMeter for API baseline checks
- JSON test data, YAML configuration, and TestNG XML suites
